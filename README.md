An entry for the [make.fun](https://make.fun/bounty/u-motasimfuad-name-the-robot-band-1ffc6a74) "Name the Robot Band" bounty. `main.ts` (Node 22, standard library only) writes one line — a name for a band made of robots, plus a few words on its hit song — to `/output/entry.txt`:

> The Rusty Bolts — hit single '404 Love Not Found' spent 12 weeks at number one, mostly because the jukebox couldn't skip it.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`. The output is deterministic: two runs write byte-identical files.
